# Propose

The **rule of three**: once is a choice, twice a coincidence, three times a convention.

Count the instances: occurrences of the pattern in the repo, plus matching **correction** signals across all area files, plus the one in front of you.

- **Under three**: when the instance in front of you is a user correction, add a correction signal to the area it belongs to (rule id `new`), so the next session can count it. A code pattern needs no signal: the repo already holds it.
- **Three or more**: name every instance, draft the rule, and ask. On the user's yes, capture it through [record.md](record.md).

Done when the instance is counted: either in a signal or in a proposal.
