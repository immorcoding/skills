# Record

A lasting decision was just made. Capture it as a rule.

1. Apply **the bar**; a decision below it ends here.
2. Read the area's file for rules the decision overlaps or contradicts. A contradiction is a **supersede**: retire the old rule through [retire.md](retire.md) in the same edit.
3. Draft the rule in the format of [STANDARD-FORMAT.md](../STANDARD-FORMAT.md), with a level: tentative → exploring; stated firmly → provisional; forced by a fixed constraint → settled (then hand it to enforcement).
4. A new area gets its own file and a line in the entry block ([ENTRY-BLOCK.md](../ENTRY-BLOCK.md)).
5. A hard-to-reverse decision also gets an ADR (see **ADRs**); link it as the rule's _Source_.

Done when the rule sits in its area file and every rule it supersedes is retired.
